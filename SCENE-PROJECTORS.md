# Scene projectors

Open **Projector**. Duplicate the selected projector (up to eight), select each instance and edit position, yaw/pitch and brightness. The original projector remains available; extra instances can be removed. Mute disables only that instance's contribution.

All instances share the same optical simulation and animation pose. They add their contributions in linear light before scene exposure/tone mapping. Each has a separate cached hard-shadow projection, using the existing opaque diffuse receiver approximation. No extra source ray trace is needed. Detector/Pattern view remains the single shared optical map, independent of scene-only brightness.

Brightness is exposure in EV: 0 = original, +1 = twice the light, -1 = half. The existing modulation panel switches to Brightness / exposure when Projector is selected, with the same sine/triangle/ramp/smooth-noise waveforms, base, depth, rate and phase. Values are bounded to -24..12 EV; use Mute for exactly zero. Each projector's modulation is independent.

Play starts a realtime visual clock at the current timeline position. Brightness runs at browser display cadence even while an optical frame is still computing. Thus during a slow optical warm-up brightness can advance ahead of computed optical poses; on warmed realtime playback both clocks run at the intended rate. Pause holds brightness; scrubbing samples brightness at the selected time. If no optics are animated, playback advances without requesting repeated optical frames.

Scene sandwich replicas follow each projector and brightness gain. Their colored preview planes are additive display visualizations, not a volumetric scattering calculation. Shadow maps are 1024 square per instance in one 4096x2048 atlas. Adding sources increases scene rasterization/shadow work, but not optical ray tracing. Optical presets preserve scene instances; the complete scene state is saved in this browser.

Browser checks: `tests/multi-source-check.html` compares one source, two overlapping sources, and a muted source on the real WebGL renderer. `tests/scene-shadow-check.html` verifies the existing sandwich hard-shadow behavior.

Select a numbered source marker in the viewport to open its controls. Use **Move** or **Rotate** at the bottom of the scene: colored endpoints constrain movement to world X/Y/Z, the centre square moves in the view plane, and rings change yaw/pitch. Shift makes dragging ten times finer; Ctrl snaps movement to 0.1 m or rotation to 5 degrees. Escape restores the starting pose. Each drag is one undo step. Camera orbit/pan remains available outside the handles. These scene-only transforms reuse the optical map and update receiver shadows.

The timeline **Speed** field (0.1–4×) retimes playback and scene brightness modulation without changing the simulation FPS, optical poses, or cache keys. Type a multiplier, drag the label, or use the mouse wheel. An 8-second loop takes 16 seconds at 0.5× or 4 seconds at 2× when delivery keeps up. Every optical frame is retained in sequence; compute or rendering bottlenecks can make actual playback slower. The setting persists in this browser and is independent of optical presets.

Viewport display controls: **Sources** hides numbered markers and transform gizmos without muting any projector. **Ambient** scales the scene fill from 0 (off) to 10×, with 1× preserving the original level; type, drag its label, or use the wheel. **Glare** adds source halos when the camera lies inside an illuminated direction of the optical map. Halo color and strength follow the map, distance, exposure and source modulation. Foreground geometry depth-tests the halo; this is an approximate screen-space glare effect, not calibrated source radiance, lens flare, eye response, or bloom around receiver highlights. These controls do not alter Pattern view or optical cache entries.

Enable **Sandwich**, then **GPU infill** in Scene to blend between computed distances. **Steps** sets subdivisions per gap (1–16, default 8); eight computed slices become 57 displayed planes at 8 steps. Existing textures are sampled in the fragment shader with no extra optical computation or cached frames. Brightness is normalized across the displayed planes; geometry shadows and per-source brightness still apply. More planes add GPU drawing cost, especially with multiple sources. This interpolates display colors, not physical ray trajectories: narrow caustics may blur or double between widely spaced samples. Increase computed slices for accuracy. Optical path tab continues to show the measured slices.

Glare now includes an illustrative front-facing lens glow outside the main beam. **Glow** adjusts its display strength (0–100×) and the in-beam halo together. The source remains dark from behind or when occluded/muted. This added glow uses map-average tint and an uncalibrated gain, so it is a visibility aid rather than a prediction of stray-light intensity.

**SSGI** adds an optional single diffuse bounce from visible surfaces. **Bounce** scales its contribution (0–10×); **Reach** sets a world-space neighborhood in metres (0.01–20), capped to 96 screen pixels for performance. Start at 1× and 1 m. The pass gathers linear projected lighting with depth/normal weighting and four depth checks between samples. It assumes neutral 0.6 reflectance and two-sided surfaces; it is not calibrated material transport. Ambient fill, source glare, and sandwich planes are excluded as emitters.

SSGI adds a second geometry pass, HDR/normal/depth buffers and a 48-sample fullscreen GPU pass. No new optical simulation or cache entries are requested. Direct lighting and antialiasing remain unchanged; setting Bounce to zero adds nothing. No temporal accumulation means no history trails, but sampling structure and camera-dependent changes remain possible. Hidden/back surfaces and off-screen bounce are missing; screen-space depth checks cannot guarantee correct occlusion. Use it as a visual approximation in Scene, not a brightness measurement. Pattern view is unaffected. Disable it to recover the original rendering cost.

**Softness** filters only the indirect-light buffer before tone mapping. Default 4 pixels reduces the hard sampling detail from narrow projected patterns; 0 disables spatial smoothing and 12 gives a broader filter. Depth and normal weights restrict bleeding across silhouettes and surface boundaries. This adds one HDR buffer and a 25-tap GPU pass. It does not blur the direct projection or introduce temporal trails.

SSGI sampling now uses stable per-pixel spiral rotation and radial jitter to reduce moiré against repeated optical lines. It trades structured aliasing for finer noise, filtered by Softness. The 48-sample gather adds GPU work compared with the original 32 samples; static renders remain deterministic, with no time-varying noise seed or history trails. Thin patterns may still alias during camera motion.
